Applied Data Science Capstone Project
This repository contains the final project for the Applied Data Science Capstone, demonstrating end-to-end data analysis, hypothesis testing, and predictive modeling using real-world datasets. The goal of this project is to apply data science techniques such as data wrangling, exploratory data analysis (EDA), visualization, and machine learning to extract meaningful insights and make data-driven predictions.

About the Project
This project aims to explore and analyze SpaceX launch data to predict whether Falcon 9 first stages will successfully land. The analysis involves collecting and preprocessing data, performing exploratory analysis, visualizing insights, building machine learning models, and evaluating their performance.

Features
Data collection using API requests and web scraping
Data cleaning and preprocessing with pandas and NumPy
EDA using matplotlib, seaborn, and plotly
Predictive modeling using scikit-learn
Interactive data visualization and insights

Technologies Used
Python (pandas, NumPy, scikit-learn, matplotlib, seaborn, plotly)
Jupyter Notebook
SQL (for querying data)
Folium (for map visualization)
GitHub (for version control and sharing)

Results & Insights
Identified key factors influencing Falcon 9 first-stage landing success
Built and evaluated multiple classification models for prediction
Visualized correlations between payload mass, launch site, and orbit type
Developed interpretive plots to support hypothesis-driven conclusions

How to Run
1.Clone this repository:
git clone https://github.com/TeluGeyasree/Applied-DataScience-Capstone-Project.git
cd Applied-DataScience-Capstone-Project
2.Install dependencies:
pip install -r requirements.txt
3.Open Jupyter Notebook and run through the analysis:
jupyter notebook
4.Explore results directly in each notebook.
